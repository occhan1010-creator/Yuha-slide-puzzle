# 絵合わせスライドパズル 3×5

推しのイラストで遊ぶ、3列×5段のスライドパズルです。
以前作ったものの復元版として、動画と記憶から仕様を再構成しました。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（GitHub Pages でもそのまま公開できます）。

1. ホーム画面で画像を選ぶ（先に管理画面から画像をアップロードしておく。数字のみモードは画像なしでも遊べる）
2. モードを選ぶ
   - イラストのみ（数字なし）
   - イラスト＋数字
   - 数字のみ
3. スタート。空白の隣のパネルをタップしてスライドさせ、絵を完成させてください
4. 完成すると「🎉パズル完成！🎉 ○○手で解けた」と表示されます

## 管理画面

- スマホのスクリーンショットをそのままアップロードできます
- ストック時に **9:15** に自動でトリミングしてから保存します（3列×5段の正方形マスに合わせた比率です）
- ストックは最大 **3種類** まで。アップロードした画像は、その端末のブラウザ内（localStorage）にだけ保存されます

## 仕様メモ

- 盤面は 3×5（15マス、空白1つ）。プレイ中はパネルに枠あり、完成画面では枠なしで元画像をそのまま表示
- シャッフルは「完成形からランダムに動かして崩す」方式なので、必ず解ける並びになります
  （完全ランダムなシャッフルだと、約半分は数学的に解けない並びになってしまうため）
